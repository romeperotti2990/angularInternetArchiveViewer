Please disable ad blockers for this site
This app requires network requests that some ad blockers block. There are no ads on this website — disabling your ad blocker for this site will ensure previews, emulator loading, and ZIP peeking work correctly.

How it works

  1. Search the Internet Archive using the top search bar.
  2. Open an item, click "Show files", then click a file name to preview it in the app.
  3. Use the Play button for emulator-supported ROMs, or view audio/video/images and documents inline.

Quick Tips

  • ZIP peeking may be slow for very large archives—be patient.
  • If a file fails due to CORS, try the download link or use the backend proxy.
  • Use filters to narrow results by mediatype (software, movies, texts, audio).
